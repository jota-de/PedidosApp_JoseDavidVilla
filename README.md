**DESCRIPCIÓN DE PROGRAMA**
----------------------------------------------------------------------------------------------------------------------------------------------
El proposito del aplicativo es registrar ordenes de pedidos de diferentes tipos de productos y realizar el calculo del costo estimado de envio que este va a tener,
ademas de determinar el medio de transporte que se va a utilizar para su entrega

----------------------------------------------------------------------------------------------------------------------------------------------
**Funcionalidades:**

| Funcionalidad    | Descripcion |
| ------ | --- |
| Calcular pedido   | Permite reliazar el regisro de un pedido guardado los datos de quien realizo el pedido, el tipo de producto, la urgencia del pedido, su peso y la distancia para la entrega del mismo  |
| Lista de pedidos  | Muestra la lista de los pedidos registrados con todos su respectiva información |
| Filtrar pedidos  | Permite filtrar la lista de pedidos acorde a el medio de transporte que se determinó para su entrega |
----------------------------------------------------------------------------------------------------------------------------------------------
